# Malu Araújo - Massoterapia e Bem-estar

Website oficial e sistema de agendamento online de **Malu Araújo Massoterapia**.

## 💆‍♀️ Sobre o Projeto

Este site foi desenvolvido com foco em alta performance, usabilidade moderna e SEO local para a cidade de São Paulo.

### Principais Recursos
- **Agendamento Inteligente**: Consulta em tempo real de horários ocupados e disponíveis via integração com Google Apps Script / Google Planilhas.
- **Redirecionamento para WhatsApp**: Confirmação direta no WhatsApp com os dados pré-preenchidos.
- **Design Responsivo & Elegante**: Layout refinado pensado para mobile e desktop.
- **Otimização para Mecanismos de Busca (SEO)**: Marcação estruturada Schema.org (JSON-LD), `sitemap.xml` e `robots.txt`.

## 📁 Estrutura de Arquivos

```
├── index.html     # Página principal da aplicação
├── style.css      # Estilos visuais e responsividade
├── script.js     # Lógica do menu, validações e consulta de agenda
├── robots.txt     # Diretrizes para indexadores de busca
└── sitemap.xml    # Mapa do site para Google e buscadores
```

## 🚀 Como Executar Localmente

Basta abrir o arquivo `index.html` em qualquer navegador web moderno ou utilizar a extensão Live Server no editor.
